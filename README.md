
# BLidaoui TV

تطبيق Android أصلي بواجهة عربية RTL وهوية داكنة حديثة.

## المزايا

- زر **تحديث** يحدّث حالة آخر مزامنة ويعرض وقت التنفيذ.
- بطاقات للمحتوى المميز قابلة للربط لاحقاً مع API أو بث مباشر.
- قسم مستقل للقنوات المفتوحة وقسم مستقل للقنوات المشفرة.
- قسم رياضي منفصل للقنوات المفتوحة والباقات الرياضية المشفرة.
- كل قسم يعرض الدول في بطاقات منفصلة مع أسماء القنوات ونوع الوصول.
- تمرير سلس وروابط خارجية مقيدة بـ HTTPS فقط.
- كل بطاقة قناة جاهزة للربط بمصدر بث رسمي مع اختيار الجودة.
- واجهة ديناميكية بحركة دخول خفيفة ودليل دول مع أعلامها.
- قسم YouTube، نافذة دردشة، واختيار اللغة.
- واجهة تسجيل دخول Gmail/Google وFacebook جاهزة لربط OAuth الرسمي.
- تحديث التطبيق عبر GitHub Releases بدلاً من Play Store.
- زر التحديث يفحص GitHub API، يقارن الإصدار، ينزّل APK الجديد ويطلب تثبيته.
- دليل قنوات حي مستورد من ملف M3U الرسمي المحدد، مع تحديث وتجميع حسب المجموعة.
- فتح القناة من القائمة عبر مشغل Android عند توفر رابط HTTPS.
- كل Push إلى الفرع `main` ينشئ GitHub Release ويرفع APK وZIP تلقائياً.
- تعطيل النسخ الاحتياطي العام ومنع اتصالات HTTP غير المشفرة.
- يعمل من Android 6.0 (API 23) فما فوق.

## التشغيل

يتطلب المشروع Android SDK مع `platforms;android-35` ونسخة Android Gradle Plugin المتوافقة. بعد ضبط `ANDROID_HOME` يمكن إنشاء نسخة debug عبر:

```bash
gradle :app:assembleDebug
```

ملف APK الناتج سيكون في `app/build/outputs/apk/debug/app-debug.apk`.

## النشر التلقائي

عند دفع أي تحديث إلى الفرع `main`، يقوم GitHub Actions ببناء التطبيق وإنشاء إصدار جديد في GitHub Releases باسم `v1.0.<رقم التشغيل>`. يجب أن تكون صلاحية Actions للكتابة مفعّلة في إعدادات المستودع.
